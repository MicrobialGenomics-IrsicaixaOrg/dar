# PrepRecipe-class object

A PrepRecipe is Recipe with the results corresponding to the steps
defined in the Recipe.

## Value

PrepRecipe-class object

## Slots

- `results`:

  Contains the results of all defined analysis in the Recipe.

- `bakes`:

  Contains the executed bakes.

- `execution`:

  Manifest containing resolved contrasts, samples removed by the
  missing-value policy, and executed or skipped methods.
