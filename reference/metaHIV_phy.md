# Phyloseq object from metaHIV project

A Phyloseq object containing abundance counts and sample_data for
metaHIV project. Count reads were annotated with Metaphlan3.

## Usage

``` r
data("metaHIV_phy")
```

## Format

A phyloseq object with 451 taxas, 30 samples, 3 sample variables and 7
taxonomic ranks.
