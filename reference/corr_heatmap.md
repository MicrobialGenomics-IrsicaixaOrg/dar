# Plot otuput of the `overlap_df` function as a heatmap.

Plot otuput of the `overlap_df` function as a heatmap.

## Usage

``` r
corr_heatmap(rec, steps = steps_ids(rec, "da"), font_size = 15, type = "all")
```

## Arguments

- rec:

  A prepped `Recipe` object.

- steps:

  Character vector with step_ids to take in account.

- font_size:

  Size of the axis font.

- type:

  Indicates whether to use all taxa ("all") or only those that are
  differentially abundant in at least one method ("da"). Default as
  "all".

## Value

heatmap

data(test_prep_rec)
